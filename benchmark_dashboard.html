Architectural Highlights (PQE)

  • Zero-Overhead Filtering: Predicates compiled directly into CPU cache loops (No dynamic planning).
  • Morsel-Driven Parallelism: Lock-free work stealing guarantees perfect CPU core utilization.
  • SIMD Acceleration: Hardware AVX2 instructions compute 8 items per cycle for arithmetic ops.

DuckDB Comparison

  • Used as the industry-standard in-memory analytical baseline.
  • Excels in heavy Hash GROUP BY operations (e.g., Q4, Q8) and complex scalar reductions (Q10) utilizing AVX-512 SIMD loops and highly optimized hash table probing.
  • Slower on raw scanning and filtering (e.g., Q1, Q2, Q3) compared to PQE due to abstract query planning, overhead of dynamic dispatch, and runtime Arrow batch conversion overhead.
